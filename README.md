# 🎯 Conditional Statements Practice Projects

Welcome to the Conditional Statements Practice repository! 

This repository contains a Python script featuring three mini-projects designed to practice conditional logic (if-else), input handling, and string/number validations.

---

## 🚀 Projects Included

1. Password Authentication:
   * Prompts the user for a username and password.
   * Case-insensitive validation using .lower().
   * Displays a customized welcome message or an error warning.

2. Word Lookup / Guessing Game:
   * Checks if a word entered by the user exists inside a predefined group/tuple of words using the in operator.

3. Number Verification:
   * Validates a numerical input entered by the user against stored target numbers.

---

## 🛠️ Concepts Applied
* Conditional logic (if / else)
* String formatting (f-strings)
* Input handling (input(), int(), .lower())
* Membership checking (in operator)
